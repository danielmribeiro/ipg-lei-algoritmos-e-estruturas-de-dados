# Algoritmos e Estruturas de Dados (Algorithms and Data Structures)
Repository for the "Algoritmos e Estruturas de Dados" course at Instituto Politécnico da Guarda (IPG), part of the "Licenciatura em Engenharia Informática" degree program. This repository contains exercises, resources, and materials related to the study of Algorithms and Data Structures.

## Course Objectives
Upon completion of this course, students should be able to:
1. Write algorithms using pseudocode and flowchart symbols.
2. Differentiate data structures and choose the best one for a given algorithm.
3. Analyze the complexity of algorithms.
4. Explain and apply sorting and searching algorithms.

## Program Contents
### Introduction to Algorithm Development
- Concept of an algorithm
- Stages of algorithm development

### Algorithmic Language
- Importance, syntax
- Flowcharts and pseudolanguage
- Simple and structured variable types
- Input and output instructions
- Control structures

### Flowcharts
- Symbols
- Applications

### Pseudolanguage
- Introduction
- Pseudocode and examples

### Data Structures
- Character strings
- Records and Files
- Arrays
- Matrices or tables
- Linked lists
- Queues
- Stacks
- Trees

### Algorithm Complexity Analysis
- Spatial and temporal complexity
- Complexity and efficiency
- “Big O” and “Little o” notations
- Function growth

### Sorting, Selection, and Searching
- Sequential and binary search
- Sorting algorithms
- Concepts of sorting algorithms
- Complexity analysis of some sorting algorithms
- Comparison of sorting algorithms

## Learning Methodologies
- The course includes expository lectures, interactive lessons, problem-solving activities, individual work, and group work.
- Students will engage in discussions with the instructor to facilitate the learning process.
- A web application will be available to assist students in writing and documenting algorithms.
- Students will have the opportunity to develop problem-solving skills through individual and group projects.

## Assessment Criteria
- **Attendance (50%)**: Determined by the ESTG Directorate.
- **Individual Assignment (20%)**: Submission in zip+pdf format, presentation on October 17, 2016.
    - Development of an algorithm.
    - PowerPoint presentation and defense.
- **Group Project (30%)**: Submission in zip+pdf format, presentation on January 9, 2017.
    - Problem-solving task.
    - Maximum of two students per group.
    - Program implementation.
    - PowerPoint presentation and defense.
    - Students are encouraged to choose project topics related to other courses, such as Algebra and Analytical Geometry, Introduction to Physics, or Introduction to Programming.
    - The instructor will provide guidance for both individual and group projects.
    - Project presentations will take place in the classroom, allowing students to observe practical applications of theoretical concepts.
- **Final Exam (Normal and Resit Periods)**: 100%
